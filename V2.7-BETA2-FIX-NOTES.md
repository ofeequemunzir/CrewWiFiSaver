# Crew Connect v2.7 Beta 2 — Wi-Fi Button & Logout Status Fix

This is a test update to the existing `v2.7-beta1-minimal` Android app.

## Changes

- **Wi-Fi icon redrawn.** Three centered thin Bézier curves and a smaller dot replace the previous cramped elliptical arcs. The button has a subtler shadow, a narrow border and a small press animation.
- **No indefinite “Checking…” display.** Unknown connectivity is shown as **Connection unavailable** rather than an endless spinner. A restricted post-logout connection is labeled **Disconnected**, and the app preserves that reading if a later probe fails.
- **Faster manual logout.** When Crew Connect already knows paid internet is active, pressing the button starts the existing logout service directly without an extra redundant precheck. The service still checks paid Wi-Fi and verifies the outcome.
- **Free WhatsApp label.** Once the free-app portal reaches its completion screen, the app displays **Free WhatsApp setup complete** underneath **Disconnected**. This means the portal steps finished; it is not proof that a WhatsApp text can actually be delivered.
- **New version:** `2.7-beta2-status-icon`, versionCode `12`. The application ID is unchanged and earlier Git branches remain available.

## Important limitations

- The logout process may briefly show **Disconnecting…** while verifying that network access changed. It does not claim success before observing a restriction. If network checks fail, the app shows **Connection unavailable**, not a false successful logout.
- The existing complimentary-app portal may still appear during WhatsApp activation. Truly invisible activation in the background, especially while locked, is not yet reliable on Android.
- A successful Google `204` response alone is not authoritative proof of paid Wi-Fi entitlement. Browser login remains separate from this app; no username or PIN is collected.

## Install test workflow (Termux)

1. Create the new branch from your latest v2.7 Beta 1 branch:
   `git -C ~/CrewWiFiSaver switch -c v2.7-beta2-status-icon`
2. Extract this patch ZIP into a separate folder:
   `mkdir -p ~/CrewConnect-v27-beta2-patch && unzip -q ~/storage/downloads/CrewConnect-v2.7-beta2-status-icon-fix.zip -d ~/CrewConnect-v27-beta2-patch`
3. Apply:
   `bash ~/CrewConnect-v27-beta2-patch/apply-update.sh`
4. Check `git -C ~/CrewWiFiSaver status --short`, stage only app/workflow changes plus this note, commit and push.
5. Build the APK in GitHub Actions on the new branch and test the states on ship Wi-Fi.

## Test

- Connected: icon is centered; tap goes to “Disconnecting…” without a second long “Checking…” stage.
- After logout: shows “Disconnected” and, once the free portal confirmation is reached, “Free WhatsApp setup complete.”
- Network failure: shows “Connection unavailable” instead of spinning forever.
- Verify actual paid internet is stopped independently and that a WhatsApp test message works. Do not infer entitlement from a single connectivity request or a portal confirmation page.
